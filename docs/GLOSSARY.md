# Glossary

| Term | Means | Not |
| --- | --- | --- |
| Polling rate | How many times a second the mouse reports, in Hz | report rate, refresh rate |
| DPI | Cursor sensitivity of one level, 50 to 26000 in steps of 50 | CPI, sensitivity |
| DPI level | One of up to four DPI values the DPI button cycles through | stage, preset |
| DPI levels | How many levels are active, 1 to 4 | stages |
| Separate X and Y | A level with different horizontal and vertical DPI | split, XY mode |
| Apply | Write the edited settings to the mouse | save, sync |
| Revert | Drop edits that were not applied | reset, undo |
